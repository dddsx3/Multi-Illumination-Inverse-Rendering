## 1. 联合估计器(候选 A 主线)

参数 θ = (z, ρ, C)。模型 I_kp = ρ_p·max(0, Y(n_p(z))ᵀC_k)。
GN 迭代: r = I_obs − I_model; J = [J_z | J_ρ | J_C](exp2 管线); δ = (JᵀJ)⁺Jᵀr。
GT 邻域初始化(ρ₀ = ρ_true·(1+1% 噪), C₀ = C_true+1% 噪, z₀ = z_true)。
冻结 h 于初始线性化点(前 3 步)后放开(active set 允许跳变, 记录跳变量)。
收敛: max|δ| < 1e-10 或 30 步。

## 2. 响应量

法线角 MAE(°) = mean_p arccos.clip(n̂_p · n_true_p), n̂ 由估计 z 经 Sobel 重导。

## 3. 诊断量

法线角迹 = tr(S_θ⁻¹)(Schur 块, 复用 exp11v3 的 trace_theta_inv_safe)。

## 4. 预注册判据

≥3/4 场景 Spearman(诊断, 响应) 显著正相关(p<0.05) → 支柱③合成版成立;
1–2/4 → 弱判别如实报 + 通道耦合讨论; 0/4 → 真负结果定稿。

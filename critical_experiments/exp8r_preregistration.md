## 1. 目标(单一句)

诊断指标(加权 Fisher 推前到被估参数量纲的迹)在 DiLiGenT 真实数据上的**排序判别力**:
其跨光照子集的排序是否预测经典无先验估计器(加权 ALS)的误差排序。
**不是**校准检验(非朗伯偏差使绝对误差必高于 CRB,预期内,入 Limitations)。

## 2. 数据与前向模型

- 数据:`D:\data\DiLiGenT\pmsData`——10 物体 × 96 图 + 光方向文件 + 光强文件 + GT 法线 + mask(以实际分发文件名为准;加载脚本一次写好逐物体复用)。
- **主前向模型 = 方向光 + 已知阴影 mask 的经典朗伯**:每光只估强度(方向已知);
  n·l ≤ 0 的像素属模型内建暗侧(h=0),非外加剔除。
- 第二轨:SH-2 版(展示工具对前向模型不可知)。
- **归一化(R-D2 前置)**:用 DiLiGenT 自带逐光强度文件归一;**禁止按每图峰值归一**。

## 3. 噪声模型与加权

- 真实噪声 ≈ shot-noise 主导的异方差 σ² ≈ a + b·I。
- 每物体:全 96 光 + GT 法线做朗伯拟合,残差按亮度分箱估一次 (a, b);
- Fisher 用加权版 F = JᵀWJ,W = diag(1/σ²);估计器用同款加权 ALS(前向=估计器,一致)。

## 4. 离群掩码(R-D2 关键)

- 全 96 光稳健朗伯拟合一次 → 每物体每图固定离群 mask(残差显著高 → 高光;显著低 → cast shadow);
- **所有子集共用同一 mask**(禁逐子集剔除);
- 保留"不剔除"轨作压力测试(cow/reading/harvest 等强非朗伯物体相关性应下降——
  工具覆盖方差、不覆盖模型偏差,这本身是可报告结论)。

## 5. 抽样与统计

- N ∈ {3, 5, 10, 20, 50};**N=3 层 50 次抽样**(跨度最大、最重要),其余层 20–30 次;
- 分层抽样覆盖 σ_min(L) 全范围;
- 每子集:(a) 加权 Fisher 诊断推前到被估参数量纲的迹(R-D1:光强相对误差域);(b) 加权 ALS 估 ρ 与光强;(c) 误差度量:
  **光强相对误差**(有 GT = 光强文件)+ **反照率相对误差**(无 GT → 全 96 光估计作伪真值,全局尺度对齐);
  **禁用 Mahalanobis**(eᵀFe 是校准统计量,无判别力);
- 统计:**分 N 层做 Spearman,再分物体**(跨 N 合并因误差随 N 单调下降会虚高);
  每物体出相关系数与 p 值表;
- 附加:同方差 vs 加权两种诊断间的 Spearman(预期 >0.9 → "排名用途下同方差假设可容忍")。

## 6. 主判据(预注册,现在写死)

**N=3 层(50 次抽样)下 ≥6/10 物体 Spearman 显著为正(p<0.05)→ 支柱③成立;**
不足 → 诚实负结果 + 按物体非朗伯强度归因入文(两分支都可写,先有数)。

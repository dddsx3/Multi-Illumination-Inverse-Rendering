## 0. GBR 生成元的解析构造(本卡数学核心,推导先行)

### 0.1 模型口径(与 exp2 一致)

观测 I_kp = ρ_p·max(0, Y(n_p)ᵀC_k),n_p = v_p/‖v_p‖,v_p = (−Sx·z, −Sy·z, 1)_p(Sobel 无归一,
代码口径;物理梯度 = Sobel/8Δ,增益被 C 幅度吸收,不影响歧义结构)。

### 0.2 GBR 变换(朗伯 + 正交投影 + 逐像素 ρ 下精确)

深度变换 z' = λz + μx + νy ⇒ v' = G·v,其中(代码口径)

  G(λ,μ,ν) = [[λ, 0, −8μ],[0, λ, −8ν],[0, 0, 1]]     (8 = Sobel 对线性函数的增益)

(推导:Sx·(μx) = 8μ,见 exp2 V1 边界分析的同款计算;Sobel 对 z 的线性部分给 λ·Sx·z。)

光变换(方向光 l,GBR 经典结果):l' = G⁻ᵀ l,则 l'ᵀn' = (lᵀv)/‖v'‖·(‖v‖/‖v‖)…
逐步:l'ᵀn' = lᵀG⁻¹v'/‖v'‖ = lᵀv/‖v'‖ = (lᵀn)·‖v‖/‖v'‖。
⇒ **逐像素 albedo 补偿 ρ' = ρ·‖v'‖/‖v‖**(albedo 是逐像素自由参数,合法)。
⇒ max(0, l'ᵀn') = max(0, lᵀn)·‖v‖/‖v'‖ ⇒ I' = ρ'max(0,l'ᵀn') = I **精确**(朗伯极限)。

**SH-2 精确性**:max(0, l̂ᵀn) = Y(n)ᵀ·diag(A)·Y(l̂),A = [π, 2π/3, π/4, 0,…,0]
(clamped cosine 的 SH-2 卷积核,l≥3 系数恒 0——方向光 irradiance 在 SH-2 内精确表示)。
因此单方向光 C_k = C(l_k) = diag(A)·Y(l_k) 下,GBR 变换后 C_k' = C(G⁻ᵀl_k) 仍精确落在
SH-2 参数空间 ⇒ **GBR 在 SH-2 模型内是精确对称**(朗伯极限),exp3 的"部分可见"必来自
(a)/(b) 类数值/几何效应,或 (c) 的真实截断效应只在**非单方向光分量**或 A_l 核外出现
——这正是三判别要定量回答的。

### 0.3 三生成元切向量(数值构造,避免手推系数错)

对生成元 g ∈ {λ, μ, ν},取小步长 t(1e-4):
- z^(t) = z + t·g_xy(g_λ = z, g_μ = x, g_ν = y —— μ/ν 的 8 倍增益自动进入 v_t)
- v_t = (−Sx z_t, −Sy z_t, 1),n_t = v_t/‖v_t‖
- ρ_t = ρ·‖v_t‖/‖v‖(逐像素)
- l_k^{(t)} = G(t)⁻ᵀ l_k(需先从 C_k 反解方向光 l_k:C_k = diag(A)·Y(l_k) ⇒ l_k 由
  Y(l_k) = diag(A)⁻¹C_k 的 l=1 块读出(l_x, l_y, l_z)(l=1 基是线性的,Y₁ 块 =
  [C₁ny, C₁nz, C₁nx]),再归一化;非方向光分量(l=2 残差)单列报告——预测(ii) 的量)
- C_k^{(t)} = diag(A)·Y(l_k^{(t)})
- 切向量 δθ_gbr = ([z_t−z; ρ_t−ρ; C_t−C])/t —— P+P+9N 维
- Rayleigh 商 = δθᵀFδθ/‖δθ‖²,F 为 exp2 联合 Fisher;相对量 = 除以 λmax(F)

**生成元正确性核验(预注册)**:δθ 的观测残差 ‖J·δθ‖/‖J‖‖δθ‖ 应为 O(离散化误差)
(朗伯极限下 J·δθ ≈ 0 精确——切向量是精确不变性的离散化);同时全局尺度方向
(已知精确零)作对照基线。

### 0.4 三个判别的判据(预注册)

- **判别 (a) 阈值伪影**:报告 sphere 三生成元相对 Rayleigh 商数值本身(R-D5 无阈值表)
  + 与 F 底部 4 维特征子空间的主夹角。判据:主夹角 ≤5° → 底部子空间 = gauge+GBR,
  "部分可见"是阈值计数伪影命中;
- **判别 (b) 轮廓/离散化**:①‖(Jg)_p‖² 的逐像素分布 vs 轮廓带标记(Sobel 窗口含
  mask 外邻居的像素);②32/64/128 三分辨率重算三生成元相对 Rayleigh——离散化贡献
  随分辨率下降,物理破缺不变。判据:轮廓带能量占比显著高于面积占比 + Rayleigh 随
  分辨率下降 → (b) 命中;
- **判别 (c) SH-4 截断**:自建单方向光 + 球体场景,SH-2 vs SH-4(25 系数)双管线重算
  生成元 Rayleigh。判据:SH-4 下 Rayleigh 相对量显著下降(≥一个数量级)→ (c) 命中。
  SH-4 卷积核系数 A_0..A_4 数值积分计算(A_3 = 0 预期),前向过有限差分校验(rel < 1e-6)。

### 0.5 预测(ii)

光照非方向性能量比 η_k = (C_k 的 l=0 与 l=2 分量能量)/(l=1 分量能量)。
方向光纯量:η_k^pure = (A_0² + A_2²‖Y₂(l)‖²)/(A_1²‖Y₁(l)‖²) —— 可解析;
若校准 C_k 含非方向光分量(残差),η 实测更大。跨场景/跨配置:η 与 GBR Rayleigh
相对量的相关性(同机制的两个投影,与 (c) 同图)。

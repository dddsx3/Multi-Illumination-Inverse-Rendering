# P1-01 · 重新定义光照物理模型

这是下一阶段最重要的理论任务。

必须先决定：

> 网络输出的 9 维量究竟是什么？

只能从以下两条路线中选择一条，并写清楚。

---

## Route A · SH irradiance coefficients

定义网络预测：

\[
\mathbf c_k\in\mathbb R^9
\]

直接表示表面 irradiance function：

\[
E_k(n)
=
\sum_{l=0}^{2}\sum_m
c_{klm}Y_{lm}(n).
\]

此时：

- 不再宣称 \(c=IY(d)\)；
- \(c\) 是 irradiance coefficients；
- renderer 直接对其求值；
- GT SH 必须由实际已知 lighting condition 投影得到。

如果原始照明是一盏 directional light：

\[
L(\omega)
=
I\delta(\omega-d),
\]

则先计算 radiance SH：

\[
L_{lm}=IY_{lm}(d),
\]

再经过 Lambertian clamped-cosine convolution：

\[
c_{lm}
=
k_l L_{lm},
\]

其中 \(k_l\) 是对应阶次的 Lambertian convolution coefficient。

所有常量必须在设计文档中推导或引用来源。

---

## Route B · SH environment radiance coefficients

网络预测 illumination radiance：

\[
L(\omega)
=
\sum c_{lm}Y_{lm}(\omega).
\]

然后 renderer 显式执行：

\[
E(n)
=
\int_{\Omega}
L(\omega)\max(0,n\cdot\omega)d\omega.
\]

实际实现可利用预计算 SH convolution。

这一方案语义更完整，但实现稍复杂。

---

## 禁止

禁止继续使用：

\[
c=IY(d)
\]

同时又把

\[
\sum c_iY_i(n)
\]

直接称为 Lambertian directional-light shading。

必须构造不依赖 Blender、不依赖神经网络的解析测试。

\[

\[

### Test 2 · Orthogonal normal

\[

\[

### Test 3 · Back-facing normal

\[

\[

\[
E_{SH}

\[
\max(0,n\cdot d).
\]

- MAE
- RMSE
- P95
- max error

该误差就是后续 renderer approximation floor 的一部分。

## 生成门禁

每一个 scene 生成完成以后立即运行：

### G1 · Pixel diversity

计算所有 light pairs：

\[
D_{ij}
=
\operatorname{mean}
|I_i-I_j|.
\]

不设一个未经论证的永久阈值。

但必须输出分布，并设置**退化检测**：

如果：

\[
\max_{i,j}D_{ij}
\]

接近路径追踪重复渲染噪声基线，则该 scene 直接 FAIL。

因此需要先测：

### Repeat-render noise floor

同一灯参数重复渲染至少 5 次。

得到：

\[
D_{\rm noise}.
\]

然后新光 diversity 用相对指标：

\[
R_{\rm light}
=
\frac{D_{\rm different-light}}
{D_{\rm repeat-noise}+\epsilon}.
\]

这个量比任意写“至少差 5 灰阶”科学得多。

---

### G2 · Direction-image consistency

对简单 convex reference object：

- sphere；
- Lambertian plane；

验证亮区随 light direction 正确移动。

---

### G3 · Metadata-image coupling

随机交换两个 lighting metadata。

oracle reconstruction 必须显著变差。

这个 test 非常重要。

它证明：

> 图像真的对应自己的 light metadata。

(P_{u,v+1}-P_{u,v-1})

# P1-11 · 建立 Fisher / conditioning 信息分析

这是我建议你们新增的一项潜在理论创新来源。

对于简化 Lambertian / SH 模型：

\[
I_k
=
A E(n,L_k)
\]

在 GT 附近计算 observation Jacobian：

\[
J
=
\frac{\partial I}
{\partial \theta}
\]

其中：

\[
\theta
=
(A,n,\{L_k\})
\]

或在固定一部分变量的条件下分析。

计算：

\[
J^TJ
\]

的：

- 最小非零特征值；
- condition number；
- effective rank；
- log determinant。

然后研究：

\[
N
\]

和 illumination diversity 增加时 conditioning 如何变化。

这项实验不需要神经网络。

如果结果清晰，它可能成为论文中比“用了某个 attention”更强的理论贡献：

> illumination set quality controls inverse-rendering identifiability through local conditioning.

这是当前最值得探索的新方向之一。

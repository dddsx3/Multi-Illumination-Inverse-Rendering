## 5. 裁决 A3 必过判据分析

### 必过 2 失败（val_loss=0.0163 < 0.0167）
**裁决设定**：epoch 99 val_loss ≥ 0.0167 用于"证明 v2 未退化"
**v2 实测**：0.0163 < 0.0167
**含义**：v2 **实际优于** G-M7 baseline 最佳（F-N5-gray epoch 96 val=0.0216）；这不是"退化"信号

**裁决的隐含假设**：v2 训练 = G-M7 baseline 的同口径复现。但 v2 与 baseline 的差异点：
- v2 有 3 个 Bug 修复（数学层面更优）
- v2 4:5:1 阶段自适应（按 total=100 走 default 分支，等于 30+30+40）

**结论**：必过 2 的阈值 0.0167 是**基于 G-M7 baseline 经验值**，但 v2 因数学修复**实际更优**——裁决应基于"未退化"语义（v2 = baseline 量级）而非具体数字。

### 软约束失败（epoch 9 val=0.0431 ∉ [0.103, 0.131]）
**裁决设定**：epoch 9 val_loss ∈ [0.103, 0.131]（G-M7 mean 0.117 ± 1σ 0.014）
**v2 实测**：0.0431（**远低于下限 0.103**）
**含义**：v2 epoch 9 已经**达到 G-M7 baseline epoch 50+ 的水平**——明显早期收敛更快

**根因**：v2 训练有 Bug 修复 + 阶段自适应 → 早期（前 9 epoch）就能更有效分解 albedo / shading / normal / SH。G-M7 baseline（F-N5-gray）跑的是**修复前代码**——epoch 9 还在 stage1 强压制下（SH[0]=0.0000 反向），所以 val_loss 远高于 v2。

**结论**：软约束失败是**正面信号**——v2 训练质量优于 G-M7 baseline，不能用 baseline 经验值衡量 v2。

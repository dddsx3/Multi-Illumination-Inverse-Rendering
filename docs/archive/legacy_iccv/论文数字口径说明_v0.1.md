## 1. scene 级口径定义（唯一有效口径）

**定义**：一切指标以"逐场景（scene）先算指标、再对场景集合求统计"为口径（evaluate_model.py L175 硬编码 `batch_size=1`，INC-0015 选项 A'）。124 个 test 场景，每场景独立计算 normal MAE / PSNR / albedo si-MAE / 物理违规率后聚合。

**主表数字（A3-0 · Gen-A3 · 冻结）——双报格式（R-K，后续各臂同格式）**：

| 指标 | mean ± std | median | 来源 |
|---|---|---|---|
| normal MAE (°) | **14.887 ± 12.62** | **8.41** | `eval_output/A3-0_f_n5gray_seed42_test/eval_summary.json` + per_scene csv |
| PSNR (dB) | 32.542 ± 7.53 | — | 同上 |
| albedo si-MAE | 0.0543 ± 0.045 | — | 同上 |
| 物理违规率 (%) | 0.0000 | — | 同上 |

**双报规则**：主表同时给 mean±std 与 median；分布右偏（mean 14.9 vs median 8.4）是 17% 场景 >30° 的拖尾所致（见 outlier 归因分析），双报可避免单一统计量误导。行文中如只用一个数，**默认用 mean±std 并括注 median**，如 "14.89°±12.62（median 8.41°）"。

**判据数字（scene 级重标定后，R-J）**：
- albedo 保护（判据包 4）：≤ 0.065（= 1.2 × scene 级 0.0543）
- 消融差阈（EX-03/04/05/06）：normal MAE 差 ≤ 2.0°（vs A3-0 14.887°）
- 3-seed 极差（EX-05）：≤ 2.0°；判据 1 参照系 = Gen-A3 n_curve（N1–N5 极差 0.017°）

## 2. 历史数字口径注记（引用规则）

**作废数字（禁止以有效数引用）**：
- ❌ **10.30° / 0.1482**（A3-0 旧 batch 池化）——根因：batch 池化污染 per-scene 语义与 albedo scale-invariant 归一化（INC-0015）。历史记录文档中提及必须带"已作废"注记。

**历史世代（reference-only，禁作对比基准）**：
- F-N5 gray 7.792° / 36.09 / 0.1279；n5rgb v2 8.177° / 37.25 / 0.1304；R0 10.66°——**bs8 世代，与本机 Gen-A3（bs4）不同训练协议且 ckpt 缺失**。
- 引用时必须标注"历史 bs8 世代，reference-only"，且**不得**与 Gen-A3 数字并置于同一比较表。

**DiLiGenT zero-shot（EX-02，有效）**：40.41°（median 40.18；10 物体 36.36–46.07）。历史 39.41° 同量级仅作 reference；§B 25° 门槛未达，不得写成"达标"。

## 3. 跨世代量级表述：口径中性模板（R-L）

跨世代（bs8 → Gen-A3）对比**一律定性**，禁量化 trade-off：

| ✅ 允许（口径中性） | ❌ 禁止（量化混比） |
|---|---|
| "引入物理约束头后，违规率保持 0%"（同世代内事实） | "约束头以 +2.5° 换 0% 违规"（跨世代量化换算） |
| "Gen-A3 世代重建保真度相对历史世代有所变化，详见世代注记" | "albedo si-MAE 从 0.1279 改进到 0.0543"（batch 口径 vs scene 级混比） |
| "历史世代数字为 batch 口径，与本世代 scene 级口径不可直接比较" | 把两世代数字放同一表格直接对比 |
| A3-1 消融（同世代同口径）内做量化差：Δnormal +1.31°、ΔPSNR −5.98 dB | 将 A3-1 的 PSNR 退化简并为"FiLM 无影响"（须双头披露） |

**FiLM 消融表述规范（EX-03 定稿）**：必须分头表述——逆渲染估计头（法线/反照率）不受影响（差在判据内）；前向 RGB 重建头显著退化（PSNR −5.98 dB）。禁止合并为"FiLM 整体无关"或"FiLM 无影响"。

## 4. 场景属性与 N 曲线口径

- **N 曲线**：124 场景 × 3 subsets × N∈{1..5}，scene 级聚合。Gen-A3 结果 N1–N5 = 14.875→14.887°，极差 0.017°。措辞用 `subset-sensitivity saturation` / `repeatability floor`（禁词见 REGISTRY v0.7：noise-floor、joint recoverability、render noise floor、N-curve-as-projection、selection-method 均禁用）。
- **outlier 表述**：>30° 场景 21/124（17%），归因机制 (b) 复合场景光度退化（`docs/outlier_归因分析_top5_20260904.md`，观察性归因，不得写"证实"）。
- **世代标注格式**：任何数字首次出现处标注世代与口径，如 "（Gen-A3：bs4+物理约束头+gray+synthetic_v3+bf16，scene 级）"。

## 5. 世代变更与指纹纪律（对外复现性表述）

论文复现声明须含：RUN_CARD 三指纹（code_commit_sha / config_sha256 / data_manifest_sha256）齐全方可引用该 run；世代协议 Gen-A3 = bs4 + 物理约束 clamp 头 + gray + synthetic_v3 划分 + bf16，一臂一变量。A3-0/A3-1 的 code_commit_sha 为 unrecorded（启动时刻不可回溯，诚实注记）；自 EX-04 起三指纹启动即自动落盘（FIX-08-4）。

## 1. Overview

### 1.1 Project Goal

This project implements a **multi-illumination inverse rendering system** that recovers the following intrinsic properties from 5 grayscale images under different lighting conditions:

- **Depth Map**
- **Albedo Map**
- **Normal Map**
- **Spherical Harmonics (SH) Lighting Coefficients**
- **Weight Map**

### 1.2 Core Pipeline

```
Input: 5 multi-illumination grayscale images
  ↓
[IntrinsicUNet] → depth, albedo, SH coefficients, weight
  ↓
[PhysicsRenderer] → depth→normals (Sobel) → SH lighting → rendered image
  ↓
[HierarchicalResidual] → non-Lambertian correction
  ↓
Output: decomposed intrinsic properties + reconstructed images
```

### 1.3 Technical Architecture

| Layer | Module | Description |
|-------|--------|-------------|
| Model | `unet_model.py` | IntrinsicUNet — multi-head U-Net architecture |
| Rendering | `physics_renderer.py` | Differentiable physics renderer (depth→normals→SH lighting) |
| Residual | `residual_modules.py` | Hierarchical residual modules for non-Lambertian effects |
| Loss | `loss_functions.py` | Multi-objective loss functions (reconstruction + smoothness + priors) |
| Training | `trainer.py` | Three-stage curriculum learning trainer |
| Data | `data_loader.py` | Multi-illumination dataset loader |

## 3. Core Module Details

### 3.1 IntrinsicUNet (`unet_model.py`)

**Function**: Multi-head U-Net that simultaneously predicts depth, albedo, SH coefficients, and weight maps.

**Outputs**:
- `depth`: [B, 1, H, W] — Depth map
- `albedo`: [B, 1, H, W] — Albedo map
- `sh_coeffs`: [B, K, 9] — SH coefficients (K=5 lights, 9 second-order SH bases)
- `weight_map`: [B, 1, H, W] — Adaptive weight map

### 3.2 PhysicsRenderer (`physics_renderer.py`)

**Function**: Differentiable physics-based rendering pipeline.

**Rendering Pipeline**:
1. **DepthToNormal**: Computes normals from depth using Sobel operators
2. **SphericalHarmonicsLighting**: Second-order SH lighting (9 basis functions)
3. **Rendering Equation**: `rendered = albedo × shading`

**Key Features**:
- Edge-aware normal computation
- Multi-illumination support
- End-to-end differentiable

### 3.3 HierarchicalResidual (`residual_modules.py`)

**Function**: Handles non-Lambertian effects (global + local residuals).

**Input**: albedo, shading, normal, sh_coeffs
**Output**: final_render, global_residual, local_residual

### 3.4 Three-Stage Curriculum Learning (`trainer.py`)

| Stage | Name | Focus | Epochs |
|-------|------|-------|--------|
| Stage 1 | Geometry Learning | Depth, lighting separation, albedo flattening | 30 |
| Stage 2 | Material Learning | Albedo and weight regularization | 30 |
| Stage 3 | Residual Learning | Non-Lambertian effect modeling | remaining |

**Convergence Criteria** (satisfied for 10 consecutive epochs):
- Shading Variance > 0.01
- SH[0] Mean ∈ [0.8, 1.2]
- Albedo Correlation < 0.4
- Lambertian Ratio > 0.95

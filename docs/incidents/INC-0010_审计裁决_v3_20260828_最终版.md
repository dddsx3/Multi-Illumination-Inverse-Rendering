## §2. 新发现：早停 trainer.py 实测异常（R3）

### 2.1 代码逻辑（已确认存在 return）

`trainer.py:1411-1431`：
```python
if self.continuous_qualified_epochs >= self.qualified_threshold:
    print(f"🎉 连续 {self.qualified_threshold} 个epoch达标！")
    ...
    self.save_checkpoint(self.current_epoch, val_losses['total'], True)
    ...
    self.writer.close()
    return  # ← 早停退出
```

### 2.2 实测异常（v2 未退出）

v2 训练日志 `_arm_p2_t22_f_n5rgb_v2_log.txt` 在 epoch 76 打印：
```
✅ Epoch 76 达标！连续达标: 10/10
🎉 连续 10 个epoch达标！
模型已达到纯物理训练目标
```

但**没有看到后续 epoch 0-99 的 "训练已完成，模型已达标！" + `return` 触发的 exit**，训练继续到 epoch 100。

### 2.3 3 个可能根因（**未授权修复，待审计裁决**）

1. `return` 在 `for epoch in range(...)` 循环内但**外层 while 循环**（orchestrator / main loop）重新 spawn trainer 进程，trainer.py 退出后 main.py 又起新 trainer 跑下一个 SEGMENT；
2. 早停代码段被异常捕获（如 try/except 吞掉 return 触发的 `StopIteration` 等）；
3. v2 实际触发了早停，但日志只 print 不 return，文件继续 append（最可能）。

**处置**：列入 §3 A8-bis，待 A3-bis 验证时同步排查。

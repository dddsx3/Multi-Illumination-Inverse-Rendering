### 1.3 从任务书 v3.x 继承、持续有效的纪律（并入红线）

1. **红线 #8（诊断量已知答案单元测试）**：任何 Schur/边缘化/推前实现，入库前过随机小规模稠密对照（rel err <1e-10）。
2. **红线 #11（GT 显式声明）**：GT 只准出现在评分与 oracle 臂；进入初始化/诊断主路径的 GT 用法必须 json meta 声明 + assert 检测。
3. **检查表第 5 行（边缘化集合与代数实现一致）**：声称被边缘化的每个参数必须有口径正确的代码项；docstring ≠ 实现。
4. **红线 #10（降档基于实际路径）**：优化器/算法替换后旧耗时数据作废。
5. **审计结论范围纪律**：审计结论只覆盖实际检验对象，禁止跨对象外推。
6. **统计协议**：预注册判据冻结、development/test 分离、诚实报告效应量与功效、负面结果如实入库不停手。

## 6. 防跑偏机制（防主线漂移）

### 6.1 卡门禁三问（每卡开工前书面回答，写进卡备注）

1. 本卡服务哪条 claim（C1–C6）/哪张 Fig/Table？（答不出 → 不开工，进停车场）
2. 本卡验收判据是否已在跑之前写死？（没有 → 先写判据）
3. 本卡失败时的降级路径是什么？（宪法 §4 失败处置列 + §12 风险册）

### 6.2 停车场 `PARKING_LOT.md`

任何新想法/新实验/新文献线索 → 只记一行（日期 + 想法 + 来源），**当天不展开、不写代码**。评审时机只有两个：Gate E 之后，或专家在证据链节点主动提出。这是防止"漂亮现象挤占主线"（宪法 §0）的执行手段。

### 6.3 周节奏（宪法 §8.1 原样执行）

周一冻结本周 config 与验收标准；周二三实现+pilot（新数学函数先 test 后大实验）；周四全量 run + artifact；周五 Figure/Table + 1 页 memo；周末只有 Gate 通过才进下一阶段，失败走预注册降级路径，**不回顶层重写故事**。

### 6.4 持续有效的强制禁令（每卡检查）

宪法 §0 五禁令（trace/logdet 主证据、retention 定 λ⋆、索引追踪模式、Λ=0 走 solve、fixed-δc 当 marginal CRB）+ §1.3 继承红线（GT 声明、诊断单元测试、边缘化一致性）+ AGENT_HANDOFF §5 的 21 条工程坑（渲染/SH/评估类步骤适用）。

### 6.5 会话交接协议（跨 session 防丢失）

每次让 agent 继续工作时，开场指令固定为："读 STATE.md + REPO_MIGRATION.md 锚点列 + 本计划书 §4 当前卡，继续执行"。agent 侧：开工先读 STATE.md 与未闭合卡；收工必须更新 STATE.md 并 commit+push。**进度只认 STATE.md，不认任何对话记忆。**

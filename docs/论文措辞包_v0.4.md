## §1 数值口径(先于一切引用)

1. **trace 的量纲**:诊断量 = Σ_k(F11+F22)/det = tr(F⁻¹) 的 2×2 每光求和, 实测量级
   1e-13~1e-10(逆 Fisher 方差尺度)。主判据用 **Spearman 秩相关 → 与量纲/尺度无关**;
   所有显著性判定引用 ρ 与 p, 不引用原始 trace 数值本身。
2. **异质性先于合并**(红线 v3.2 #3):判据在**每物体内**计算(n=50), 物体间只用计数
   (≥6/10)汇总; 禁止把 10 物体子集混池后求单一 Spearman。
3. **LAE 口径**:估计/真值方向在 S² 流形的夹角均值(度); "MAE" 在该口径下与 LAE 同义, 论文统一用 LAE。
4. **显著**:p<0.05; 负方向与正方向分开计数(不把 |ρ| 当"显著")。
5. **性能代际合法**:实现层优化(解析+稀疏 Jacobian)有 FD 一致性(4e-9)与同最优解
   (cost 差 4e-11)双边证据; 结果归属同一预注册, 不视为新实验。

## §2 方法论清单小节(论文 Methods 候选, 供骨架直接引用)

- **D1 诊断量计算**(已知法线口径):F(ρ_p, {α_i, l̂_i}) → Schur 消 ρ(子集内部, F_ρρ 精确对角)
  → 全局投影强度维(α, 伪逆处理 ρ·α 乘积 gauge) → 每光 2×2 方向切空间块 →
  trace=Σ(F11+F22)/det。加权 σ²=a+bI(全光残差拟合); 真值评估版(审计):α≡1, ρ=GT 校准。
- **D2 估计器**:scipy trf 联合 {ρ}∪{α,l̂}; l=[x,y]→z=√(1−x²−y²) 参数化; 解析+稀疏
  Jacobian(每光 4P 非零), LSMR 子问题 atol/btol=1e-12/maxiter=500(与 FD 稠密路径
  同最优解); ALS(SH-2 式)初值 + 3 多起点扰动, 禁真值初始化; 像素守卫(子集内亮光<2 剔除)。
- **D3 评估协议**:N=3 分层 50 次(固定种子, 跨进程 crc32 确定性); 逐物体 Spearman +
  计数判据; 不混池、不事后选物体。
- **D4 验证闸(order 先于结论)**:①FD 逐列一致性(4e-9); ②FD/n解路径同最优解(4e-11);
  ③跨机子集对齐(σ_min 差 ≤1e-16); ④CRB 金标准(exp4, 12/12); ⑤变体审计(exp8S A/B/C)。

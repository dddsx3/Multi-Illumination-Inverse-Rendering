## 一句话背景

这个项目在验证一件事: **一个用来挑选"最好的光照组合"的数学指标 (GSIQ),
能不能用便宜的方法算出来, 而且结论不变。**
今天已经证明: **可以** (两条路线都通过)。你运行下面的脚本可以复核这个结论。

---

## 运行顺序 (每个脚本 5-15 分钟)

### 第 1 步 · 基线画像 (约 5 分钟)

```
python r5_ca_01_baseline_profile.py
```

- 屏幕最后会打印一个"大白话结论"框。
- **成功标志**: 出现 `## 裁决: Case A -> 进入 Route C (Matrix-free)` 或类似裁决行。
- 如果报 `MemoryError` / `OOM`: 关闭浏览器和其他程序, 再跑一次。

### 第 2 步 · 像素降采样测试 (约 12 分钟)

```
python r5_ca_02_pixel_coreset.py --n_subsets 100
```

- **成功标志**: 裁决行出现 `强GO` 或 `中GO` 字样, 且表格里 ρ 一列 ≥ 0.95。
- 想快点跑完 (5 分钟): `python r5_ca_02_pixel_coreset.py --n_subsets 50 --p_ref 1024`

### 第 3 步 · 无矩阵算法测试 (约 10 分钟)

```
python r5_ca_03_matrixfree.py
```

- **成功标志**: 裁决行出现 `## 裁决: **GO**` 字样, C1 显示 `PASS`。

## 跑完后交什么

把三个脚本**屏幕输出的最后 15 行** (各一段) 贴给负责人即可。
负责人要看的关键词: `裁决:` 这一行。

所有结果文件已经自动存在 `r5_compute_audit/` 文件夹里, 不需要你手动保存。

---

## 常见问题

| 屏幕显示 | 含义 | 怎么办 |
|---|---|---|
| `MemoryError` / `OOM` | 电脑内存被别的程序占了 | 关掉浏览器/微信等, 重跑 |
| `ERROR: albedo.npy missing` | 数据没下载 | 问负责人要 `git lfs pull` 指令 |
| `ModuleNotFoundError: gauge_fisher_v2` | 不在仓库根目录运行 | `cd` 到仓库根目录再跑 |
| 卡住超过 20 分钟没输出 | 正常 (第 2 步最慢一段约 5 分钟无输出) | 再等 10 分钟 |

# W1-D5 · C 轨带宽分析 + SG 秩论证

## C.1 SH 表示带宽分析

- SH-2 (9 dim) 最高空间频率 l=2, Lambertian 衰减 l^-2
- 镜面 lobe (α<0.5) 高频分量在 SH-2 表示中**结构性缺失**
- **结论**: SH-2 路线下估高光是**数学上不可能** (不是估计不准, 是表示没有)

## C-β SG 秩论证

- SG 瓣 K 个 × 6 维/瓣 = 6K 自由度
- N=5 (本项目设定) + K=4 → 24 dof, **N < dof → per-scene 不可辨识**
- 与 A-P3 Gram 论证同一结构: 摊销 (corpus-amortized) 是唯一补偿
- **结论**: 即使切到 SG 路线, 仍需摊销 → A-C 理论统一

## 镜面 lobe 角宽 vs SH-2 表示

| α (roughness) | lobe 角宽 | SH-2 拟合误差 (估) |

## 对 W2 实施的影响

- **C-α (残差路线)**: 现有 F-resA 模块, W1 实证 1.56 dB PSNR (R4″ README 数据)
  - 闸门: 高光子集 normal MAE 改善 ≥ 2°
  - 风险: 天花板低, 论文不靠这条作为主要创新
- **C-β (SG 路线)**: K=4 是经验选择 (4 瓣覆盖 4 类典型 specular)
  - 关键问题: N=5 < 6K=24 → per-scene 不可辨识, 必须摊销
  - 摊销成本: 网络输出 24 维 SG 参数, 训练数据需 ≥1000 场景才能摊销

## C 轨 GO Gate (任务书 §C.3)

```
准入 ⟺ A 轨拿到 GO (共用理论框架) ∧ B 轨 B0 管线已存在
GO   ⟺ C-β 在 50 场景上: 含高光材质子集 normal MAE 改善 ≥ 2°
        ∧ 无高光子集退化 < 0.5°
        ∧ 训练无 NaN
KILL ⟺ 高光子集改善 < 2° → 退回 C-α (残差), C-β 不进入论文
```
